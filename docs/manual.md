# የፕላን ተቆጣጣሪ ፕላትፎርም — የተጠቃሚ መመሪያ

ከፕላን ውጭ የሚደረግ ግንባታን በሳተላይት ለመከታተል · ስሪት 1.0 · ጥቅምት 2026

## 1. ይህ ፕላትፎርም ምንድን ነው?

ይህ ፕላትፎርም የከተማውን የመሬት አጠቃቀም ፕላን ከሴንቲኔል-1 የራዳር ሳተላይት ምስሎች ጋር እያነጻጸረ **ከመረጡት ቀን ጀምሮ በፕላኑ ዞኖች ላይ የተጀመረ የግንባታ እንቅስቃሴ ወይም ለውጥ ያለበትን ቦታ በካርታ ያሳያል።** ሥራውን በራሱ በየሳምንቱ ያድሳል።

### ምን ማድረግ ይችላል

- በክልከላ ዞኖች (አረንጓዴ ቦታ፣ መንገድ፣ ወንዝ ዳር፣ የተከለለ ቦታ) እና ከፕላን ወሰን ውጭ (150 ሜትር ቀለበት) ያለ የግንባታ እንቅስቃሴ መጠቆም።
- በግንባታ በሚፈቀድባቸው ዞኖች ውስጥ "እንቅስቃሴ ተጀምሯል" ማለት።
- ለውጡ የተጀመረበትን ግምታዊ ቀን እና የራዳር ምልክት ግራፍ ማሳየት።

### ምን ማድረግ አይችልም (ወሳኝ)

- ነጠላ ትናንሽ ቤቶችን በትክክል አይለይም (የምስሉ ጥራት 10 ሜትር ነው)።
- የግንባታ ሽፋን (BAR)፣ ቁመት ወይም የፈቃድ ሁኔታን አይፈትሽም።
- **ጥቆማ ማለት የሕግ ማስረጃ አይደለም፤ ወደ ቦታው ምርመራ የሚመራ ፍንጭ ነው።** ሁልጊዜ በአካል ወይም በምስል ያረጋግጡ።
- የሐሰት ማንቂያም ሊኖር ይችላል (ለምሳሌ የሰብል እድገት፣ የዝናብ እርጥበት)።

## 2. ዳሽቦርዱን መክፈት

1. ዳሽቦርዱን በማንኛውም አሳሽ (Chrome፣ Edge ወይም Firefox) ይክፈቱ፤ አድራሻው **https://bellstrillion-arch.github.io/Plan-Monitor/** ነው።
2. ገጹ ሲከፈት በግራ በኩል የቁጥጥር ፓነል፣ በቀኝ ካርታ ይታያል። ስልክ ላይ ፓነሉ ከካርታው በላይ ይሆናል።
3. ከላይ በግራ ፓነል ውስጥ **ቀይ "DEMO" ማስጠንቀቂያ** ካዩ፣ ይህ የማሳያ ሰው ሠራሽ ዳታ ነው፤ እውነተኛ ግኝት አይደለም። እውነተኛ ዳታ ሲሆን ማስጠንቀቂያው አይታይም።

| ተንሸራታች | የመነሻ ቀኑን በመጎተት ይቀይራል |

### ቀለሞች

- **ለስላሳ ቀለም ያላቸው ፖሊጎኖች** የፕላኑ ዞኖች ናቸው።
- **ቀይ ሳጥኖች** መካከለኛ እምነት ያላቸው ጥቆማዎች ናቸው።
- **ብርቱካናማ ሳጥኖች** ዝቅተኛ እምነት ያላቸው ጥቆማዎች ናቸው (ትንሽ ስፋት ወይም የራዳር ምልክት መቀነስ)።

## 4. ከመረጡት ቀን ጀምሮ የተፈጠረ ለውጥ ማየት

1. **Start date** ሳጥን ውስጥ ጠቅ አድርገው ቀን ይምረጡ፤ ወይም ተንሸራታቹን ይጎትቱ፤ ወይም ከ30d/90d/180d/1y/All ይምረጡ።
2. ካርታው ወዲያውኑ ይቀየራል፤ ከተመረጠው ቀን በኋላ የተገኙ ጥቆማዎች ብቻ ይቀራሉ።
3. ከታች **"N alerts since …"** የሚለው መስመር ጠቅላላ ብዛት እና ስፋት (ሄክታር) ያሳያል።
4. ከታች ያለው ዝርዝር ጥቆማዎችን ከአዲሱ ወደ አሮጌው በቀን ቅደም ተከተል ያሳያል።

የመነሻ ቀን ከክትትሉ መጀመሪያ (በነባሪ ጥር 2026) በፊት መሆን አይችልም፤ ከዚያ በፊት ያለው ጊዜ የንጽጽር መነሻ (baseline) ነው።

## 5. አንድ ጥቆማ መመልከት

1. በካርታው ላይ ቀዩን/ብርቱካናማውን ሳጥን ወይም በዝርዝሩ ውስጥ አንድ ረድፍ ጠቅ ያድርጉ። ካርታው ወደዚያ ይጠጋል።
2. ከታች የሚከተለው ይታያል፦
   - የመሬት አጠቃቀም ዓይነት እና `alert_type`
   - **Detected** (የተገኘበት ቀን)፣ **direction** (increase = ምልክት ጨመረ፤ decrease = ቀነሰ)፣ **z** (የለውጡ ጥንካሬ፤ ከፍ ሲል ጠንካራ)፣ ስፋት በሄክታር
   - **ግራፍ፦** ቀይ መስመር VV፣ ሰማያዊ መስመር VH (የራዳር ምልክት በdB)፣ ነጠብጣብ ቋሚ መስመር የተገኘበትን ቀን ያሳያል።

### ግራፉን ማንበብ

- ከነጠብጣቡ መስመር በኋላ **ሁለቱ መስመሮች በአንድ ጊዜ ወደ ላይ ዘለው በዚያው ከቆዩ** (ደረጃ እንደሚወጣ) ይህ ለአዲስ ግንባታ የሚያመች ቅርጽ ነው።
- ምልክቱ ወደ ላይ እና ወደ ታች በየጊዜው ከተወዛወዘ ወይም በአንድ ሳምንት ብቻ ከተነሳ ጫጫታ ወይም ወቅታዊ ለውጥ ሊሆን ይችላል።

## 6. ጥቆማን መገምገም

1. ጥቆማ ከመረጡ በኋላ **Review** ምናሌ ውስጥ **confirmed** (ተረጋግጧል) ወይም **false alarm** (የሐሰት ማንቂያ) ይምረጡ።
2. ምርጫዎ በዝርዝሩ ውስጥ ከጥቆማው ጎን ይታያል (`?` = ገና አልተገመገመም)።
3. ሁሉንም ግምገማዎች ለማስቀመጥ ከታች **Export reviews (CSV)** ይጫኑ፤ ፋይሉ ወደ ኮምፒውተርዎ ይወርዳል።

> **ማስታወሻ፦** ግምገማዎች የሚቀመጡት በዚህ አሳሽ ውስጥ ብቻ ነው። ሌላ ኮምፒውተር ላይ አይታዩም፤ የአሳሽ ታሪክ ከተሰረዘ ይጠፋሉ። ስለዚህ በየጊዜው CSV ይላኩ እና ለአስተዳዳሪው ያስረክቡ።

## 7. ጥቆማዎችን እንዴት መተርጎም

| ጥቆማ | ትርጉም | ምን ማድረግ |
|---|---|---|
| `violation_candidate` በክልከላ ዞን | ግንባታ የተከለከለበት ቦታ ላይ ለውጥ | በቅድሚያ ይመርምሩ |
| `violation_candidate` በ`outside_plan` | ከፕላን ወሰን ውጭ ባለው ቀለበት ውስጥ ለውጥ | በቅድሚያ ይመርምሩ፤ ግን እርሻ ሊሆን ይችላል |
| `activity` | ግንባታ በሚፈቀድበት ዞን እንቅስቃሴ | ጥሰት ማለት አይደለም፤ ፈቃድ ካለ ያረጋግጡ |
| confidence `medium` (ቀይ) | ምልክቱ ጨመረ፤ ቦታው ሰፋ ያለ ነው | ይመርምሩ |
| confidence `low` (ብርቱካናማ) | ምልክቱ ቀነሰ ወይም ቦታው ትንሽ ነው | አነስተኛ ቅድሚያ |

### የሐሰት ማንቂያ የተለመዱ ምንጮች

- የሰብል እድገት እና የዝናብ እርጥበት (በተለይ ከፕላን ውጭ ባለው የእርሻ ቀለበት)።
- በፓርኪንግ ውስጥ የቆሙ ተሽከርካሪዎች፣ በገበያ ውስጥ ጊዜያዊ ድንኳኖች።
- በአንድ ቀን በብዙ ቦታ የተገኙ ጥቆማዎች (የምስል ተፅዕኖ ሊሆን ይችላል)።
- የሳተላይት መሠረት ምስሉ (Esri) ሊያረጅ ይችላል፤ ምስሉ ላይ ግንባታ አለመታየቱ ጥቆማው ስህተት ነው ማለት አይደለም።

### የሚመከር የምርመራ ቅደም ተከተል

1. የቅርብ ጊዜ እና `medium` እምነት ያላቸውን ጥቆማዎች በክልከላ ዞኖች/ከፕላን ውጭ መጀመሪያ ይምረጡ።
2. ግራፉን ይመልከቱ (ደረጃ የሚመስል ዝላይ አለ?)።
3. በሳተላይት ካርታ እና ከተቻለ በሌላ የቅርብ ምስል ያረጋግጡ።
4. በመስክ ይጎብኙ፤ ውጤቱን በ**Review** ይመዝግቡ።

## 8. አዲስ ከተማ መጨመር (ለአስተዳዳሪ)

### ሀ. የፕላን ፋይሉን ማዘጋጀት

ፋይሉ **GeoJSON** መሆን አለበት፤ መጋጠሚያው **WGS84 (EPSG:4326)** ነው፤ እያንዳንዱ ፖሊጎን `land_use` የተባለ አንድ አትሪቢዩት ይኖረዋል (ከተፈለገ `name` ማከል ይቻላል)። ሻፕፋይል ወይም KML ካለዎት በQGIS ውስጥ ይክፈቱት፣ `land_use` አምድ ይጨምሩ፣ ከዚያ Export → GeoJSON (CRS: EPSG:4326) ያድርጉ።

| `land_use` እሴት | ትርጉም | ግንባታ |
|---|---|---|
| `residential` | መኖሪያ | ይፈቀዳል |
| `mixed_use` | ድብልቅ አገልግሎት | ይፈቀዳል |
| `commercial` | ንግድ | ይፈቀዳል |
| `industrial` | ኢንዱስትሪ | ይፈቀዳል |
| `institutional` | የመንግሥት/ማኅበራዊ አገልግሎት | ይፈቀዳል |
| `green_open_space` | አረንጓዴ እና ክፍት ቦታ | ተከልክሏል |
| `road_transport` | መንገድ እና ትራንስፖርት (ፓርኪንግን ጨምሮ) | ተከልክሏል |
| `water_riparian` | ወንዝ እና ውሃ ዳር | ተከልክሏል |
| `reserved` | የተከለለ ወይም ሌላ የማይገነባ ቦታ (እርሻ፣ ገበያ፣ ወዘተ ከዚህ ይግቡ) | ተከልክሏል |

እሴቶቹ በትክክል በዚህ ፊደል (ትናንሽ ፊደላት፣ ከስር ሰረዝ ጋር) መጻፍ አለባቸው። ከዚህ ዝርዝር ውጭ የሆነ እሴት ሥርዓቱ ያቆማል፤ በሎግ ውስጥ የተፈቀዱትን ዝርዝር ያሳያል። ከፕላን ወሰን ውጭ ያለው ቀለበት በራሱ ይጨመራል።

### ለ. መስቀል

1. GitHub repo ውስጥ `cities` አቃፊን ይክፈቱ።
2. **Add file → Upload files** ይጫኑ።
3. የከተማ አቃፊ ይጎትቱ (ስሙ ፊደላት፣ ቁጥሮች እና ከስር ሰረዝ ብቻ፣ ለምሳሌ `bahir_dar`)፤ ውስጡ `plan.geojson` ይኑር።
4. ከተፈለገ `config.json` ጨምረው ስሙን ያስተካክሉ፦ `{"name":"Bahir Dar","gee_project":"ethiopian-lu-plan-monitor"}`።
5. **Commit changes** ይጫኑ።

### ሐ. ማረጋገጥ

1. **Actions** ትር → አዲስ ሩጫ በራሱ ይጀምራል (ቢጫ ክብ)።
2. ከ2–10 ደቂቃ በኋላ አረንጓዴ ምልክት ማየት አለብዎት።
3. ዳሽቦርዱን ያድሱ (F5)፤ ከተማው በ**City** ምርጫ ውስጥ ይታያል።

## 9. ሥራው እንዴት እንደሚሠራ እና እንዴት መፈተሽ (ለአስተዳዳሪ)

- ሥርዓቱ በየሰኞ እና ፋይል ሲጨመር ወይም ሲቀየር በራሱ ይሠራል። በእጅ ለማስኬድ፦ **Actions → Monitor cities → Run workflow**።
- **እውነተኛ ዳታ መሆኑን ለማረጋገጥ፦** repo → `docs/data/<ከተማ>/meta.json` ይክፈቱ። `"demo": false` እና `"generated"` የቅርብ ቀን መሆን አለበት።
- **ሎግ ማንበብ፦** Actions → ሩጫ → `monitor (<ከተማ>)` → "Run python src/monitor.py…" ይዘርጉ። "latest S1 image used" የቅርብ ቀን እና "N units, M alerts" መታየት አለባቸው።
- ነባሪ የንጽጽር መነሻ ዓመት (baseline) 2025 ነው፤ ክትትሉ ከጥር 2026 ይጀምራል። ለመቀየር `config.json` ውስጥ `baseline_start` እና `baseline_end` ይጻፉ።
